# Ad Creative Provenance

Every `AdvertisingCreativeAsset` records media provenance.

## Sources

| Source | Label |
|--------|-------|
| ASSET_LIBRARY | Approved asset from Asset Library |
| AI_IMAGE_STUDIO | Generated by AI Image Studio |
| AI_CAROUSEL_STUDIO | Generated by Carousel Studio |
| AI_VIDEO_PIPELINE | Generated by AI Video/Reels Pipeline |
| UPLOAD | User upload |
| EXTERNAL | External source — verify rights |

## Synthetic media

AI-generated assets are marked `isSynthetic: true` with disclaimer:

> AI-generated image. Not a real customer, office, result, or event unless explicitly sourced and labelled.

## Rules

1. Do not claim generated images depict real customers, offices, results, or events without explicit sourcing.
2. `assertSyntheticLabelling()` warns on mislabelled synthetic media.
3. Cross-tenant asset access is blocked — `attachAsset` verifies `organisationId` and `brandId`.

## Performance linking

`AdvertisingCreativePerformanceLink` prepares post-publish linking to `MarketingCreative` imported performance data. **No performance is inferred before publication.**
