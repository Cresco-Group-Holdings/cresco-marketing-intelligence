# Task 10 Scope Freeze

Task 10 is the final productisation gate before the Launch Readiness Audit. This document records intentional exclusions.

## Allowed in Task 10

- Bug fixes and UX fixes
- Route cleanup, redirects, and navigation finalisation
- Launch copy (website, empty states, terminology)
- Missing empty states and loading/error improvements
- Final integration fixes and responsive fixes
- E2E launch suite and documentation
- Feature flag cleanup and dev-route gating
- Production acceptance fixes

## Explicitly excluded (post-launch backlog)

- New product modules or major architecture
- Threads, Pinterest, Bluesky, Telegram, Medium, Substack production integrations
- Advanced Reddit automation
- Predictive CAC/LTV, MMM, probabilistic attribution
- Autonomous budget changes or autonomous commenting
- Enterprise SSO and white-label agency system
- Advanced custom report builder
- AI video generation platform
- Full SEO growth campaign
- Full documentation portal / support software
- Full mobile optimisation for complex analytics

## Task 10 focus

Polish the existing product into one coherent commercial experience:

**Website → Signup → Onboarding → Connect → Understand → Create → Publish → Measure → Act → Pay / Upgrade**
